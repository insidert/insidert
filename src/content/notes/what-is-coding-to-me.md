I have started coding since 2010. But serious coding started in 2013. By serious I mean, building real-projects. I learnt code to build projects. I loved every bit of it. 

Learning by practising. Watching tutorials and coding along. Reading blog posts and documentation sites. Asking on stackoverflow. Meditating on the road-blocks. Thinking long hours about bugs and new features. Letting the brain figureout and getting that voila moments.

Code is meditation to me. Coding helped me focus. To stabilize my emotional swings. It is a skill that I loved and cherised every moment. 

I have been coding for many years now. Not a moment or not a single minute I felt coding is daunting and I need to giveup.
