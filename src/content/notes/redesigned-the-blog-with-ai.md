I like to code this website with new technologies or with latest and simple libraries and frameworks. I wrote how this blog has taken shape over the years in [this blog post.](/notes/how-i-built-this-blog/)

Now with AI, I want to update my blog. I have first iterated a simple and clean version. It was good compared to what was existing. 

Then I want to make this little fun. So I prompted to make the website little more fun and energitic. 

The framework is still Astro JS. I have used Cursor to build this blog. Cursor then used React to build the animations and layouts.

I have not used React before. I like writing Vue. Now that we do not have to care about the code anymore, I let it go.

Few improvements:

- The site now uses a simple key, '/' on keyboard to go directly to the search page and start typing.
- The site can be toggled between light mode and dark mode. The choice will be remembered.
- The blog nomenclature is updated to notes.
- The tags are still there.
- You can now subscribe to new articles. Leave your email on the footer.
- If you want to send your thougts for a post / note, look for a simple form below the note.


I like coding so much. I should say I love coding. But now, the AI tools have taken out the joy of writing it. I still can code without the AI assistance. But I will have to spend time.

Time is money. Do I have time to learn and build like the old ways? I may have. Will the world wait for me? Ofcourse not. Then, should I still go the old way? I do not know.
